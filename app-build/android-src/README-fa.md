# بیلدکیت اندروید — سامانه الو شتاب (نسخهٔ 1.1.0)

پوستهٔ رسمی اندروید (APK) سامانه الو شتاب — نمایشگر امن وب‌اپ با آدرس قابل‌تنظیم.

## تازه‌های 1.1.0 (versionCode 2)
- صفحهٔ خطای فارسی با دکمهٔ «تلاش دوباره» در قطع شبکه یا دامنهٔ غیرفعال
- مجوز موقعیت مکانی (GPS) برای ثبت مختصات مهندس/مشتری در پنل مدیریت
- پشتیبانی انتخاب فایل (آپلود فاکتور و مدارک در وب‌اپ)
- اسپلش برند (گرادیان سبز عمیق + آیکون مرکزی) تا نخستین رندر
- اصلاح نام اپ به «الو شتاب» و پشتیبانی کامل RTL

## محتویات
| فایل/پوشه | کارکرد |
|---|---|
| `AndroidManifest.xml` | شناسهٔ `ir.aloshetab.app`، مجوز اینترنت + موقعیت مکانی، هدف API ۳۴ |
| `java/ir/aloshetab/app/MainActivity.java` | WebView امن (فقط HTTPS، بدون Mixed Content، بازگشت، خطای فارسی، GPS، انتخاب فایل) |
| `assets/config.json` | آدرس سرویس — پیش از بیلد نهایی، دامنهٔ خود را بگذارید |
| `res/` | آیکون، اسپلش برند (`res/drawable/splash.xml`) و رنگ سازمانی |
| `build.sh` | اسکریپت ساخت و امضا (با `-encoding UTF-8` و `zipalign -p`) |
| `aloshetab.keystore` | کلید امضا (رمز: `aloshetab1405`) — برای به‌روزرسانی‌های آینده حفظ شود |

## پیش‌نیاز
- JDK 17+ (فقط جاوا؛ نیازی به Gradle نیست)
- Android cmdline-tools با `build-tools;34.0.0` و `platforms;android-34`

## ساخت
```bash
export ANDROID_HOME=/path/to/android-sdk
# اگر دامنهٔ نهایی دارید، اول config.json را ویرایش کنید:
nano assets/config.json
./build.sh AloShetab.apk
```

## نصب روی گوشی
1. فایل `AloShetab.apk` را به گوشی منتقل کنید.
2. برای اطمینان از سالم رسیدن فایل، SHA-256 آن را مقایسه کنید:
   - ویندوز: `certutil -hashfile AloShetab.apk SHA256`
   - لینوکس/مک: `sha256sum AloShetab.apk`
3. روی فایل بزنید؛ اگر پیام «منابع ناشناس» آمد، اجازهٔ نصب را برای مرورگر/فایل‌منیجر فعال کنید.
4. اپ با نام «الو شتاب» نصب می‌شود.
